# Навигация

Статус: черновик (спринт 2)

## Нижние вкладки

| Вкладка | Смысл | Наполнение по фазам |
|---|---|---|
| Профиль / Аватар | Я, серия, XP | Фаза 1: профиль + кнопка разминки. Фаза 2: аватар |
| Лента | Короткие видео | Фаза 1: заглушка. Фаза 3: вертикальный скролл |
| Дейлики | Задание дня | Фаза 1: заглушка. Фаза 2: таймер и задание |
| Социалка | Друзья, рейтинг | Фаза 1: заглушка. Фаза 3: лидерборд и пары |

## Стек поверх вкладок

- Онбординг (модальный/стек), всегда с «Пропустить опрос»
- Модалка «серия спасена щитом»
- Paywall (фаза 4)
- Плеер «повторить упражнение» из ленты (фаза 3)
