# Полный план разработки

Канон чекбоксов — этот файл. Корень `ROADMAP.md` только ссылается сюда.

Стек и продукт: максимальный Time-to-Market, привычка без вины, «любое движение считается».

Сейчас: **фаза 1, одиночный день**. Тема тёмная, мята. Данные — JSON-файлы и локальный Node, не Supabase. Пять вкладок уже в баре.

## Фаза 1: Инициализация и прототип MVP (недели 1–2)

Цель: инфраструктура и кликабельный скелет с живой записью дня.

### Спринт 1: среда и данные

- [x] Expo Managed Workflow + JavaScript (JSX)
- [x] NativeWind и дизайн-токены (тёмная мятная тема)
- [ ] Проект Supabase и схема — цель, в коде нет:
  - `profiles` (id, username, avatar_url, core_streak)
  - `activities_log` (id, user_id, type, duration, created_at)
  - `streaks` (id, user_id, current_streak, freezes_left, last_activity_date)
- [x] Auth: почта и пароль, сессии в файле. Google / Apple — позже

### Спринт 2: навигация и Quick-Start

- [x] Нижние вкладки (портрет): Главная | Тренировки | Друзья | Калории | Профиль
- [x] Опрос после регистрации пропускаемый: карточка «подстроим план», не стена. Тело для ккал — на Калориях
- [x] Минутная разминка сразу после регистрации засчитывает серию
