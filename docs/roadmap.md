# Полный план разработки

Канон чекбоксов — этот файл. Корень `ROADMAP.md` только ссылается сюда.

Стек и продукт: максимальный Time-to-Market, привычка без вины, «любое движение считается».

Сейчас: **фаза 1, спринт 1**.

## Фаза 1: Инициализация и прототип MVP (недели 1–2)

Цель: инфраструктура и кликабельный скелет с живой базой.

### Спринт 1: среда и БД

- [x] Expo Managed Workflow + JavaScript (JSX)
- [x] NativeWind и дизайн-токены (светлая зелёная тема)
- [ ] Проект Supabase и схема:
  - `profiles` (id, username, avatar_url, xp, level, core_streak)
  - `activities_log` (id, user_id, type, duration, created_at)
  - `streaks` (id, user_id, current_streak, freezes_left, last_activity_date)
- [ ] Auth: Email / Google / Apple через Supabase

### Спринт 2: навигация и Quick-Start

- [x] Нижние вкладки (портрет): Арена | Тренинг | Награды | Топливо | Профиль
- [x] Опросник после регистрации (2 экрана, JSON пользователя)
- [ ] 10-секундная активность: «Засчитать разминку» → запись в БД + анимация успеха

## Фаза 2: ядро игры (недели 3–5)

Цель: удержание — прощающая серия, дейлики, аватар.

### Спринт 3: гибкая серия (Duolingo-style)

- [ ] Виджет серии (пламя, счётчик)
- [ ] Edge Function ежедневной проверки:
  - нет активности, есть щит (`freezes_left`) → списать щит, серия жива
  - щитов нет → обнулить серию
- [ ] Модалка: «Твоя серия спасена щитом! 🛡»

### Спринт 4: дейлики и аватар

- [ ] Экран челленджа (Chess.com): таймер до конца дня, задание ~2 минуты (например, 20 приседаний)
- [ ] Аватар + уровни XP с анимацией шкалы при логе активности
- [ ] Бейджи за 3 / 7 / 30 челленджей подряд

## Фаза 3: контент и соцслой (недели 6–8)

Цель: виральность и залипательная лента.

### Спринт 5: вертикальная лента (TikTok-style)

- [ ] Supabase Storage под видео (сжатие и оптимизация)
- [ ] Вертикальный скролл (`FlashList` / `FlatList`), играет только видимый ролик
- [ ] Реакции: лайк-огонёк 🔥, «Повторить упражнение»

### Спринт 6: друзья и лидерборды

- [ ] Подписки / друзья
- [ ] Лидерборд суток (сброс раз в 24 часа), экстра-XP топ-3
- [ ] Парная серия: общий счётчик с другом; пропуск одного бьёт общую серию

## Фаза 4: экономика, ADHD-полировка, релиз (недели 9–10)
