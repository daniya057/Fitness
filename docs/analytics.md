# Аналитика

Статус: черновик (инструмент — фаза 4, словарь событий ведём с MVP)

Инструмент: Amplitude **или** Mixpanel. До подключения SDK события описываем здесь и логируем no-op / dev console.

## Воронка, которую нельзя потерять

1. Установка → открытие
2. Auth успех / ошибка
3. Онбординг: старт, шаг, **пропуск**, финиш
4. Первая активность (`warmup_10s`) — время от установки
5. Второй день с активностью (удержание D2)
6. Срабатывание щита vs обнуление серии
7. Закрытие дейлика
8. Показ / покупка paywall

## Именование

`snake_case`, глагол: `onboarding_skipped`, `activity_logged`, `streak_shield_used`.

Свойства: `activity_type`, `duration_sec`, `streak_count`, `source_screen`.
