# База данных

Статус: черновик схемы фазы 1  
Платформа: Supabase PostgreSQL + RLS

Все таблицы завязаны на `auth.users`. Клиент не обходит RLS.

## Фаза 1

### `profiles`

| Колонка | Тип | Смысл |
|---|---|---|
| `id` | uuid PK, = `auth.users.id` | Пользователь |
| `username` | text unique | Ник |
| `avatar_url` | text null | Файл в Storage |
| `xp` | int default 0 | Опыт |
| `level` | int default 1 | Уровень |
| `core_streak` | int default 0 | Зеркало основной серии (дублирует удобный рид) |

Триггер: при signup создавать строку `profiles` и `streaks`.

### `activities_log`

| Колонка | Тип | Смысл |
|---|---|---|
| `id` | uuid PK | Событие |
| `user_id` | uuid FK → profiles | Кто |
| `type` | text | Например `warmup_10s`, позже типы челленджей |
| `duration` | int | Секунды |
| `created_at` | timestamptz | Когда |

RLS: пользователь читает/пишет только свои строки (чтение чужих — отдельная политика для ленты/соцслоя в фазе 3).

### `streaks`

| Колонка | Тип | Смысл |
|---|---|---|
| `id` | uuid PK | |
| `user_id` | uuid unique FK | |
| `current_streak` | int | Текущая серия дней |
| `freezes_left` | int | Щиты заморозки |
| `last_activity_date` | date null | Последний день с активностью (календарный, TZ пользователя позже) |

Поле `freeze_shield` в роадмапе = `freezes_left > 0` (щит как запас, не отдельный буль).

## Storage (фаза 3 и аватар)

Бакеты: `avatars`, `feed-videos`. Пути вида `{user_id}/...`. Публичное чтение аватаров — по решению на старте бакета; видео — по политике фазы 3.
