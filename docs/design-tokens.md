# Дизайн-токены

Статус: черновик (спринт 1, NativeWind)

Пока бренд-палитры нет — не выдумывать маркетинговое имя. Зафиксировать нейтральный тёмный «дофаминовый» набор при подключении NativeWind и дописать hex сюда.

## Ожидаемые токены

- `color.bg`, `color.surface`, `color.accent` (огонь серии)
- `color.success` (закрыл активность)
- `color.danger` (серия под угрозой, не «ты плохой»)
- Шрифт: системный до выбора брендового; затем `expo-font`

Классы Tailwind мапятся на эти токены в `tailwind.config`.
