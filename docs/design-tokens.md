# Дизайн-токены

Статус: принято

Стиль: **Modern Minimalist & Clean Green** — светлая премиальная тема, много воздуха, тонкие линии, плоский дизайн.

## Цвета

| Токен | Hex | Tailwind | Где |
|---|---|---|---|
| Фон | `#FFFFFF` | `bg-canvas` | Экран |
| Карточка | `#F8F9FA` | `bg-card` | Панели, карточки |
| Акцент | `#2E7D32` | `bg-accent` / `text-accent` | Успех, кнопки, серия |
| Чернила | `#1A1A1A` | `text-ink` | Заголовки, контуры |
| Вторичный текст | `#666666` | `text-mute` | Подписи, таймер |
| Акцент мягкий | `#E8F5E9` | `bg-accent-soft` | Фон щита |
| Мята | `#C9EBD6` | `bg-mint` | Карточки «Задание дня» и «Достижения» |

Серия на Арене на порогах 1 / 3 / 10 / 20 / 100 дней берёт отдельные цвета (мята → зелёный → золото → тёмно-зелёный). Это не токены таббара.

Группы на Тренинге тоже не таббар: всё тело — мята, жим — голубой, тяга — зелёный, ноги — янтарь, кор — сирень, кардио — розовый, растяжка — бирюза. Код: `src/features/workouts/look.js`.

## Форма

- Скругления: `16–24px` (`rounded-2xl` / `rounded-3xl`)
- Без тяжёлых теней: максимум едва заметная, лучше тонкая обводка `#1A1A1A` на 6–8% или серый разделитель
- Тактильность: `Haptics.ImpactFeedbackStyle.Light` на каждое действие
- Кнопки: круглые, `15px` semibold. Основная — `bg-accent`, вторичная — `bg-card`, мягкая — `bg-mint`.
- Таббар: иконка + подпись, активный пункт на мяте.
