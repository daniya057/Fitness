# Главная (Арена)

Статус: в работе  
Файл: `src/features/arena/arena.js`

Макет как в референсе (вертикальный телефон):

- Шапка **Серия** + аватар справа
- Зелёная полоса серии и пламя с числом
- Мятная карточка **Задание дня** с кольцом обратного отсчёта до полуночи (формат `Ч:ММ`)
- Полоса веса: текущий → цель
- Мятный блок **Достижения**: Тонус, Сила, 7 дней

Тап по заданию дня ведёт в Тренинг. Тап по аватару — в Профиль.
