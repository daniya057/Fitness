# Пять вкладок

Статус: в работе  
Ориентация: вертикальная (portrait).

Нижний бар в потоке: у активной вкладки иконка и подпись, у остальных иконка. Главная · Тренировки · Друзья · Калории · Профиль. Справа сверху на вкладках (кроме Профиля) значок лица и окантовки.

Каждый экран — вертикальный скролл или колонка, без ландшафтной сетки.

Профиль: опросник сеткой (колонки, вес, ИМТ), без целей и выбора значка. «Так видят друзья» внизу, можно скрыть. Друзьям ИМТ не показывается.

Калории: «Итого за день», рацион на остаток, полка частых продуктов без запроса, поиск, «Блюда» и остальные категории под «Ещё», сканер (на вебе подсказка «лучше с телефона»), счётчик граммов, дневник. Норма ккал округляется до 10. Чёрный список подписан «Не предлагать». Повтор того же продукта спрашивает.

Главная: карточка «на сегодня», крупный блок серии, вечернее напоминание. Затем «Как ты?» / обзор недели, ккал. В день отдыха — три дейлика. В день плана дейлики скрыты. Медалей мало. Баннер, если друг позвал.

Друзья: поиск по имени уже зарегистрированных. Пустой список — «Пока никого» и ссылка-приглашение. Без друзей окно «Позови друга» один раз за аккаунт (`inviteHidden` в файле). Карточка со серией, тап — открытый профиль, «Позвать». Входящие заявки — «Принять» / «Отклонить».

Награды: сетка медалей со стека (не вкладка), открытые со свечением акцента.

Тренировки: план недели из опросника (если сегодня выходной — строка об этом), календарь недели по умолчанию, месяц по тапу. Каталог под «Ещё программы». Плюс своей тренировки в шапке. Play мятный. Зал: «Сделал» / «Пропустил» на подходе, кольцо на отдыхе 90 сек.
