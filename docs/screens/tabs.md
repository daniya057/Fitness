# Пять вкладок

Статус: в работе  
Ориентация: вертикальная (portrait).

Нижний бар в потоке: у активной вкладки иконка и подпись, у остальных иконка. Главная · Тренировки · Друзья · Калории · Профиль. Справа сверху на вкладках (кроме Профиля) значок лица и окантовки.

Каждый экран — вертикальный скролл или колонка, без ландшафтной сетки.

Профиль: опросник сеткой (колонки, вес, ИМТ), без целей и выбора значка. «Так видят друзья» внизу, можно скрыть. Друзьям ИМТ не показывается.

Калории: «Итого за день», цели белка/жиров/углеводов из опросника, поиск карточками с «+» и бейджами Б/Ж/У, сканер, счётчик граммов, дневник.

Главная: карточка «на сегодня», крупная серия и щит, затем компактный «Как ты?» / обзор недели (разворачиваются), ккал, задания. Разминки на главной не дублируются, если сегодня отдых. Баннер, если друг позвал.

Друзья: поиск по имени уже зарегистрированных. Пустой список — «Пока никого», не повтор плейсхолдера. Карточка со серией, тап — открытый профиль, «Позвать».

Награды: сетка медалей со стека (не вкладка), открытые со свечением акцента.

Тренировки: план недели из опросника (если сегодня выходной — строка об этом), календарь недели по умолчанию, месяц по тапу. Группы 30–90 мин и чип «Короткие», Play мятный, сессия с автотаймером.
