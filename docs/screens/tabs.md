# Пять вкладок

Статус: в работе  
Ориентация: вертикальная (portrait).

Нижний бар: Арена · Тренинг · Награды · Калории · Профиль.

Каждый экран — вертикальный скролл или колонка, без ландшафтной сетки.

Калории: плашка съедено/цель ккал, поиск по таблице и магазинам, сканер, счётчик граммов, дневник.

Арена: крупная серия и щит, цель/съедено ккал, компактное задание дня.

Награды: сетка медалей, открытые со свечением акцента.

Тренинг: группы, уровни сложности, сессия с автотаймером.
