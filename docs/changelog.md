# Журнал документации

## 2026-09-20

- После регистрации — обязательный опрос (тело + цели). Ответы в `data/users/{id}.json`. Главная, тренинг, топливо и профиль читают эти поля.
- В профиле можно поменять имя, статус, вес, рост, дату рождения, цели и дни недели. Почта только для входа.
- Единый стиль вкладок: мятные карточки, круглые кнопки, подписи на таббаре.
- Админка `/admin`: статистика, карточки людей без паролей, правка заданий дня.
- Ссылки и ключи собраны в папке `keys/`.

## 2026-09-19

- Тема: светлый эко-минимализм (`docs/design-tokens.md`). UI на JS, не TS.
- Первый экран: Арена.
- Главная как в референсе: серия, кольцо «Задание дня», вес, достижения. Нижний бар — только иконки.
- Вход обязательный. Анкеты — файлы в `data/users/`.
- Собрана первая версия `docs/` из продуктовой спеки, стека и роадмапа.
