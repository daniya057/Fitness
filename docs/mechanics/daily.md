# Ежедневные челленджи

Статус: черновик (спринт 4)

Стиль Chess.com: одно понятное задание до конца дня.

## Экран

- Таймер обратного отсчёта до полуночи (TZ: на MVP UTC, затем локаль пользователя)
- Короткое описание, ~2 минуты: пример «20 приседаний»
- CTA закрыть / засчитать (без простыни инструкций)

## Награды

Закрытие пишет `activities_log` и даёт XP (формула — в [avatar.md](avatar.md)).  
Бейджи за серии закрытых дейликов: 3 / 7 / 30 подряд.

## Контент заданий

Каталог заданий появится в спринте 4. До этого экран — заглушка во вкладке «Дейлики».
