# Ежедневные челленджи

Статус: в работе

На Арене три мини-тренировки на UTC-день. Сервер выбирает их из скрытых сессий по человеку и дате, в течение дня список не меняется. Тап открывает именно эту сессию. В общем списке тренинга их нет.

## Экран

- Таймер обратного отсчёта до полуночи (TZ: на MVP UTC, затем локаль пользователя)
- Короткое описание, ~2 минуты: пример «20 приседаний»
- CTA закрыть / засчитать (без простыни инструкций)

## Награды

Закрытое задание копится в `dailyDoneCount`. Достижения: одно задание, пять заданий, день когда закрыты все три. Скрытое — семь таких дней. Если за день закрыты все три, сервер один раз добавляет щит (`freezesLeft`). Опыта за это нет.

## Контент заданий

Тексты арены и тренинга лежат в `data/content/catalog.json`. Их меняет админка (`/admin`). Приложение читает `GET /catalog`. Полный дейлик Chess.com — спринт 4.
