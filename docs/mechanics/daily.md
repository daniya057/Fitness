# Ежедневные челленджи

Статус: в работе

На Арене три мини-тренировки на локальный день человека. Если сегодня по плану есть тренировка (не отдых), этот блок скрыт — один список дел, карточка плана. Сервер выбирает три сессии на дату, в течение дня список не меняется. Тап открывает именно эту сессию. В общем списке тренинга их нет. Подсказка не дублирует название.

## Экран

- Таймер обратного отсчёта до полуночи в часовом поясе человека.
- Короткое описание, ~2 минуты: пример «20 приседаний»
- CTA закрыть / засчитать (без простыни инструкций)

## Награды

Закрытое задание копится в `dailyDoneCount`. Достижения: одно задание, пять заданий, день когда закрыты все три. Скрытое — семь таких дней. Щит за день один раз: закрыт план, закрыты все три задания или любой зачёт дня (разминка тоже). Опыта за это нет.

## Контент заданий

Список трёх заданий сервер собирает из сессий с `daily: true` в `data/content/workouts.json`. Админка этот список не редактирует. Полный дейлик Chess.com — спринт 4.
