# Быстрый старт

Статус: в работе

## Поток

1. Регистрация (имя, почта, пароль)
2. Опросник: тело, цели, шесть коротких вопросов и рекомендации. Один раз, не при каждом входе
3. Главная: чек-ин, план на сегодня, задание дня, вес из опросника

Тело и цели пропустить нельзя, пока нет `onboardingDone`. Доп. вопросы можно пропустить по одному, вкладки откроются после `quizDone`. Квиз при установке без аккаунта больше не используется.

После опроса на Арене сразу есть план на сегодня и утренняя и вечерняя разминки по минуте — этого хватает, чтобы засчитать день.
