# Быстрый старт и разминка

Статус: черновик (спринт 2)

## Зачем

Сразу после установки человек должен **закрыть первую активность**, не проходя квиз.

## Поток

1. Auth (спринт 1)
2. Онбординг → «Пропустить опрос» доступен всегда
3. Главный экран: кнопка **«Засчитать разминку»**
4. По тапу: запись в `activities_log` (`type: warmup_10s`, `duration: 10`)
5. Обновить серию/XP (минимум лог; полный XP-пайп — спринт 4)
6. Анимация успеха (Moti/Reanimated), без длинного текста

## Продуктовые ограничения

- Не требовать камеру, геолокацию или видео для этой кнопки
- Повтор в тот же день — разрешён как лог, но серию инкрементить один раз за календарный день
