# Быстрый старт

Статус: в работе

## Поток

1. Регистрация (имя, почта, пароль)
2. Сразу Главная: разминка «начать». План по умолчанию — дом, час, пн · ср · пт
3. Карточка «подстроим план» — по желанию. Тело для ккал — когда зайдёшь на Калории

Вкладки открыты сразу. Пропуск опроса ставит дом / 60 минут / три дня. Квиз при установке без аккаунта не используется.

На Главной сразу есть план на сегодня и минутная разминка — этого хватает, чтобы засчитать день.
