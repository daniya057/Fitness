# Прощающая серия

Статус: черновик (спринт 3)

## Правило

Пропуск дня **не** обнуляет серию, если есть щит (`freezes_left > 0`). Щит списывается, серия сохраняется. Щитов нет — `current_streak = 0`.

Это не наказание: модалка «Твоя серия спасена щитом! 🛡».

## Клиент

Виджет: пламя + число. Данные из `streaks` (+ зеркало `profiles.core_streak` для быстрого рида).

## Сервер

Edge Function по крону (раз в сутки, после полуночи в выбранной TZ; на MVP — UTC, зафиксировать в changelog при смене):

1. Для каждого пользователя: была ли активность за вчера (`activities_log`).
2. Если да — ничего (серия уже обновлена при логе).
3. Если нет и `freezes_left > 0` — декремент щита, серия без изменений, флаг для пуша/модалки при следующем входе.
4. Если нет и щитов 0 — `current_streak = 0`.

Инкремент серии — при первой активности календарного дня (клиент + желательно проверка на сервере, чтобы не накрутить).

## Покупка щитов

Фаза 4: магазин (монеты с XP или IAP через RevenueCat).
