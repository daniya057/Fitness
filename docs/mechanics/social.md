# Социальный слой

Статус: черновик (спринт 6)

## Друзья

Подписки / добавление в друзья. Realtime — активность друзей (когда дойдём).

## Лидерборд суток

Таблица на 24 часа, затем обнуление. Топ-3 получают экстра-XP.  
Сброс — Edge Function / cron, не только клиент.

## Парная серия (дуэль)

Общий счётчик дней, когда **оба** активны. Пропуск одного рвёт общую серию (личные серии живут по своим щитам).

Тон: соревнование без унижения. Пропуск пары — факт, не «ты подвёл друга» в копирайте.
