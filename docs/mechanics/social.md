# Социальный слой

Статус: в работе

## Друзья

Вкладка **Друзья** в нижнем баре (вместо Наград). Поиск по имени в приложении: от 2 букв, до 12 совпадений. Имена не уникальны — в списке аватар и серия, выбираешь человека. Ника `@` нет.

Дружба взаимная: нашёл → заявка. В списке человек появляется, только когда примет. Если оба отправили друг другу — сразу друзья. Отклонить снимает заявку, не банит. Снять друга — с карточки, с обеих сторон. Себя добавить нельзя. Чужие почта, вес и дневник еды не отдаются.

Если друзей ещё нет, окно «Позови друга» один раз за аккаунт: скопировать ссылку `/invite/{id}` или поделиться, «Больше не показывать» пишет `inviteHidden` в JSON человека. На другом устройстве с тем же входом окна нет. Ссылка остаётся кнопкой на экране. Поиск без запроса ничего не показывает; «никого» — только после имени. Если запущен `npm run share`, в ссылке публичный адрес туннеля, не localhost. По ссылке без входа сначала регистрация, потом заявка тому, кто пригласил.

Карточка друга: знак, имя, справа крупная плашка серии (пламя и число), «сегодня / не сегодня» мельче. Тап открывает **открытый профиль**: серия, щиты, число тренировок, закрытые задания, типы, медали. Почта, вес и дневник еды не входят. В своём Профиле тот же блок внизу, свёрнут: «Показать» / «Скрыть».

Код: `src/features/friends/`, `server/friends.js`. Поля: `friends` (взаимные id), `incomingRequests` (кто прислал заявку), `nudges` (`from`, `at`, `seen`). Старые односторонние подписки при чтении списка становятся заявками. `GET /people/:id` отдаёт публичную статистику.

## Пинк

Кнопка **Позвать**. Пишет входящее приглашение другу. Баннер «Имя позвал на тренировку» на Друзьях и Главной, тап — на Тренировки и помечает прочитанным. Пушей нет. Кулдаун 4 часа на пару. Тон без вины.
