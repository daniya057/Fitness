# Аватар, XP, бейджи

Статус: черновик (спринт 4)

## Аватар

Базовый персонаж на вкладке Профиль/Аватар. Кастомизация скинами — фаза 4 (магазин).

## XP и уровень

Поля: `profiles.xp`, `profiles.level`.  
При логе активности шкала заполняется анимацией (Reanimated/Moti).

Черновая формула (уточнить в спринте 4, не блокирует MVP-лог):

- `warmup_10s` → небольшой XP (например 5)
- закрытый дейлик → больше (например 25)
- топ-3 суточного лидерборда → экстра (фаза 3)

Пороги уровня — таблица в этом файле, когда утвердим числа.

## Бейджи

Ачивки за 3 / 7 / 30 дейликов подряд. Хранение — отдельная таблица в спринте 4, не раньше.
