# Вертикальная лента

Статус: черновик (спринт 5)

## Цель

Залипательный скролл коротких вертикальных роликов (TikTok-style).

## Техника

- Storage Supabase: сжатие и оптимизация до/при загрузке
- Список: `FlashList` предпочтительно, иначе `FlatList`
- Играет **только видимый** элемент (`expo-video` + кэш)
- Не грузить сырой поток на каждый маунт

## Реакции

- Лайк-огонёк 🔥
- «Повторить упражнение» — быстрый старт той же активности

## Фаза 1

Вкладка «Лента» — заглушка, без плеера.
