# Архитектура

Статус: принято (паттерны до появления репо)

## Принципы

- Модульный JavaScript (JSX), функциональные компоненты и хуки. Без TypeScript в UI
- UI-экраны отдельно от бизнес-логики
- Сложный фетч и стейт — кастомные хуки
- Структура **по фичам**, не по техническим слоям в корне
- Стили: классы NativeWind. `style={{}}` только если значение реально динамическое на кадр
- Явные интерфейсы пропсов и строк БД
- Запросы с учётом RLS
- Медиа ленты — через кэш
- Без `TODO: implement later`, если задачу не отложили явно

## Целевая раскладка

```
app/                      # Expo Router: вкладки и онбординг
features/
  streaks/
  feed/
  avatar/
  daily/
  social/
  activity/               # быстрый лог разминки
shared/
  ui/
  lib/                    # supabase client, query client
supabase/
  migrations/
  functions/
docs/
```

## Состояние

- **TanStack Query** — профили, лента, лидерборды, история активностей
- **Zustand** — идущая тренировка, таймер дейлика, черновик аватара, флаги онбординга на устройстве

## Навигация

Нижние вкладки с фазы 1: Профиль/Аватар | Лента | Дейлики | Социалка.  
Экраны следующих фаз до своего спринта — лёгкие заглушки, не полная реализация.
