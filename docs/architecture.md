# Архитектура

Статус: в работе

## Принципы

- Модульный JavaScript (JSX), функциональные компоненты и хуки. Без TypeScript в UI
- UI-экраны отдельно от бизнес-логики
- Сложный фетч и стейт — кастомные хуки
- Структура **по фичам**
- Стили: классы NativeWind. `style={{}}` только если значение динамическое на кадр
- Без `TODO: implement later`, если задачу не отложили явно

TanStack Query, папка `supabase/`, лента `features/feed` — цель, не факт.

## Состояние

- **Сервер** — `data/users/{id}.json`, клиент дергает `/me`
- **Zustand** — идущая тренировка и таймер
- Часовой пояс: поле `timeZone`, сутки `YYYY-MM-DD` в этой зоне (дефолт `Europe/Moscow`)
