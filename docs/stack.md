# Стек

Статус: принято  
Цель стека: Time-to-Market, 60 FPS, поддержка небольшой командой.

## Фронтенд

| Слой | Выбор | Зачем |
|---|---|---|
| Приложение | Expo Managed + React Native, TypeScript | Expo Go, iOS и Android без глубокой нативки |
| Стили | NativeWind (Tailwind) | Быстрая вёрстка, хорошо генерируется в Cursor |
| Серверное состояние | TanStack Query | Кэш, лента, бесконечный скролл |
| Клиентское состояние | Zustand | Тренировка, таймер, кастом аватара |
| Анимации | Reanimated + Moti | Нативный поток, Duolingo-feel |
| Видео | `expo-video` (предпочтительно), иначе `react-native-video` | Вертикальная лента с кэшем |

## Бэкенд (Supabase)

| Часть | Назначение |
|---|---|
| PostgreSQL | Профили, друзья, лидерборды, логи активностей |
| Auth | Email, Google, Apple |
| Realtime | Лидерборды, чаты, активность друзей |
| Storage | Видео ленты, аватары |
| Edge Functions (Deno / TS) | Сгорание серий, награды по таймеру, валидация платных турниров |

## Монетизация и аналитика

| Слой | Выбор | Зачем |
|---|---|---|
| IAP | RevenueCat | Подписки, скины, щиты без ручной боли сторов |
| Аналитика | Amplitude или Mixpanel (выбор при старте фазы 4, до этого — заглушка событий) | Дроп на онбординге и в первый месяц |

Не дублировать платежи через сырой StoreKit/Play Billing, если RevenueCat уже закрывает сценарий.
