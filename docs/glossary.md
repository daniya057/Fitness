# Словарь

| Термин | В коде / БД | Смысл |
|---|---|---|
| ИМТ | `bodyMassIndex` | Вес в кг делить на квадрат роста в метрах. Ориентир ВОЗ, не диагноз |
| Фокус | `quiz.focus` | Что важнее сейчас: привычка, похудение, сила, энергия, осанка |
| Место | `quiz.place` | Где занимается: дом, дом с гантелями, зал, везде. Зал подставляет сессии на тренажёрах |
| Чек-ин | `checkins` | Короткий дневной опрос: силы, сон, боль, время |
| Серия, стрик | `current_streak`, `core_streak` | Дни подряд с активностью |
| Прощающая / гибкая серия | forgiving streak | Серия не падает в 0, если есть щит |
| Щит, заморозка | `freezes_left`, freeze shield | Списывается за пропущенный день |
| Дейлик | daily challenge | Задание до конца суток |
| Разминка 10 сек | `type: warmup_10s` | Мгновенный лог с главного экрана |
| Парная серия | buddy streak | Общая серия двух людей |
| Лидерборд суток | daily leaderboard | Сброс раз в 24 часа |
