# Авторизация

Статус: черновик (спринт 1)

Провайдер: **Supabase Auth**.

## Способы входа

1. Email (magic link или пароль — уточнить при подключении проекта; дефолт: email + пароль для MVP, magic link если проще в консоли)
2. Google
3. Apple (обязателен для iOS-ревью, когда пойдём в TestFlight)

## Поведение

- Сессия хранится SDK Supabase на устройстве
- Нет аккаунта → нельзя писать в `activities_log` (RLS)
- Онбординг **не** заменяет логин: сначала сессия, квиз можно пропустить
- Анонимный вход не в скоупе фазы 1, пока явно не решим иначе
