# Фитнес-игра (рабочее название)

Социальная фитнес-игра: лента как TikTok, привычки как Duolingo, дейлики как Chess.com, социальное доказательство как Strava.

Миссия: **привычка без вины**. Любое движение считается — даже растяжка на 2 минуты.
