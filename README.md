# Фитнес-игра (рабочее название)

Социальная фитнес-игра: лента как TikTok, привычки как Duolingo, дейлики как Chess.com, социальное доказательство как Strava.

Миссия: **привычка без вины**. Любое движение считается — даже растяжка на 2 минуты.

| | |
|---|---|
| Аудитория | Gen Z, молодые миллениалы, СДВГ |
| Стек | Expo (JSX), NativeWind, Supabase, RevenueCat |
| Сейчас | Фаза 1 — экран Арена |
| Язык | Русский (UI, доки, комментарии) |

## Запуск

```bash
npm install
npm run server
npx expo start --web
```

Без `npm run server` регистрация не сохранится в `data/users/`.

Веб: `npx expo start --web`. Телефон: Expo Go.
